# General Surgery Diploma Review

مستودع مركزي لبناء ومراجعة بنك أسئلة دبلوم الجراحة العامة، مع تنظيم المصادر والمحاضرات وبيانات الاستيراد وأدوات التحقق.

## قواعد العمل

- الفرع `main` هو النسخة المستقرة للمشروع، ويُعامل كفرع محمي منطقيًا حتى تفعيل Branch Protection في إعدادات GitHub.
- لا يُسمح بالتعديل المباشر على `main`.
- لكل مهمة Issue واحدة واضحة، ويُنشأ فرع مستقل مرتبط برقم الـ Issue، مثل `content/issue-12-trauma`.
- كل تغيير يجب أن يمر عبر Pull Request مرتبط بالـ Issue.
- يجب مراجعة Pull Request من عضو آخر قبل الدمج.
- يجب أن تنجح فحوص التحقق الآلية قبل الدمج عندما تُضاف CI إلى المشروع.
- لا تُشارك رموز الوصول أو كلمات المرور، ولا تُمنح صلاحيات للمستخدمين دون قرار صريح.
- عند تعارض التعديلات، تُجرى المراجعة البشرية قبل اختيار النسخة النهائية.

## البنية الأولية

- `source-manifests/`: فهارس المصادر وروابطها وبياناتها الوصفية.
- `lectures/`: مراجع المحاضرات والمواد التعليمية المنظمة.
- `question-bank/`: ملفات بنك الأسئلة وإصداراته.
- `web-import/`: مواد أو نتائج الاستيراد من الويب.
- `scripts/`: أدوات التحقق والتحويل والتوليد.
- `.github/`: قوالب التعاون وإعدادات سير العمل.

## سير العمل المختصر

1. افتح Issue تصف المهمة ومجال الملفات.
2. أنشئ فرعًا من `main` خاصًا بالمهمة.
3. نفّذ التعديل واختبره محليًا.
4. افتح Pull Request واربطه بالـ Issue.
5. اطلب مراجعة مستقلة.
6. ادمج التغيير بعد نجاح الفحوص والمراجعة.
