# Web Import

يحتوي هذا المجلد على مخرجات وبيانات استيراد المواد العامة من الويب قبل تنظيفها أو اعتمادها في بنك الأسئلة.

يجب الاحتفاظ بمصدر كل مادة وتاريخ جلبها وحالتها: `raw` أو `reviewed` أو `accepted` أو `rejected`. لا يُنقل أي محتوى إلى بنك الأسئلة قبل التحقق من المصدر والحقوق والملاءمة التعليمية.
